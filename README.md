# xhs-fav-archiver

小红书收藏夹**本地存档 + 本地搜索**小工具。

收藏夹攒了上万条，怕作者删帖、怕自己找不到——这个工具把收藏夹抓成本地 SQLite，
再配一个本地网页查看器：搜索、自己打标签、点 tag 顺藤摸瓜、批量清理，全在本地完成。

## ⚠️ 非常重要的风控警告！！！
**本脚本涉及登录态下的小红书自动化操作，官方检测到会弹出警告、限流甚至封号！**
- 我本人测试爬了300条左右的收藏，就收到了官方"不允许使用AI操作账号"的警告
- 目前小红书对Playwright/自动化工具的检测非常严格，包括浏览器指纹、行为节奏、批量操作频率
- 强烈不建议直接运行本脚本，本项目仅作为**爬虫/反风控学习的案例**，不要用于实际批量操作！
- 作者不对任何因使用本脚本导致的账号封禁/警告承担责任！

## 功能

**抓取（crawl.py）**
- 滚动抓取收藏夹列表：标题 / 作者 / 点赞 / 封面链接 / 带 token 的原链接
- 逐条打开详情，抓正文里的 `#话题标签` 和发布时间，存进 SQLite
- 分批跑（默认每批 100 条），断点续抓：已抓过的自动跳过，下次接着来
- 顺序安全：**标签成功写库后，才会取消收藏**；空标签 / 异常一律不动收藏状态
- 反风控：每条间隔随机抖动；检测到滑块验证自动暂停，等手动过完再继续
- 每批结束自动备份 db 到 `backups/`（只留最近 10 份）

**查看（serve.py）**
- 一键搜索：标题 / 小红书标签 / 自己打的标签 / 作者，可勾选"只搜标签"
- 卡片墙：封面懒加载（首次打开才下载，缓存本地），点卡片弹出详情窗
- 点任意 tag 直接按它搜；热门 tag 词频云；搜索历史（localStorage 留存）
- 弹窗里给自己打标签（回车添加 / 点 chip 移除）
- 多选模式批量软删除，回收站可恢复

技术栈：Python + Playwright（调本机 Chrome）+ Flask + SQLite，无前端构建，单文件即可跑。

## 安装

```bash
pip install -r requirements.txt
```

要求：Python 3.10+，本机已安装 Chrome（脚本通过 `channel="chrome"` 调系统 Chrome，
不需要另外下载 Playwright 自带浏览器）。

## 使用

```bash
# 第一步：抓收藏夹
python crawl.py
```

会弹出一个**干净的 Chrome**（不保存登录态，每次手动登录最省事）：
1. 手机号 + 验证码登录小红书
2. 点头像进个人主页 → 切到「收藏」tab
3. 回到终端按回车，它就开始滚动抓取

每批 100 条结束自动退出，多跑几批直到收藏夹清空。中途触发风控验证会自动暂停，
你手动过完滑块后按回车继续。

```bash
# 第二步：打开本地查看器
python serve.py
```

浏览器访问 <http://127.0.0.1:5000>。

## 注意事项

- **取消收藏是真实线上操作**，脚本已做安全顺序（先落库后取消），但请先小批量试跑确认行为符合预期
- 触发风控就把 `crawl.py` 里的 `BATCH_SIZE` 调小、等待区间调大
- 仅供个人学习存档使用，请遵守平台规则，不要高频批量操作
- 抓取频率建议自己把握，出问题概不负责

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `crawl.py` | 抓取脚本 |
| `serve.py` | 本地查看器（Flask） |
| `xhs.db` | 数据文件，运行后自动生成 |
| `covers/` | 封面缓存目录，运行后自动生成 |
| `backups/` | db 自动备份目录，运行后自动生成 |
